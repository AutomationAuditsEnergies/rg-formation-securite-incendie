# RG Formation – Site formations sécurité incendie

Site vitrine statique (HTML/CSS, sans dépendance) présentant les formations SSIAP, SST, SIP et incendie de RG Formation.

- `index.html` : contenu de la page
- `style.css` : mise en forme

Les éléments à compléter sont marqués `À COMPLÉTER` dans `index.html` (coordonnées, mentions légales, formation SIP).

Aperçu local : ouvrir `index.html` dans un navigateur.
