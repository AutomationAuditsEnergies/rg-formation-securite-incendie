# Vigieo – Site formations sécurité incendie

Site vitrine statique (HTML/CSS, sans dépendance ni build) : SSIAP 1, SST, EPI et exploitation SSI.

- `index.html` : accueil (formations, public, méthode, engagements, FAQ, contact)
- `ssiap-1.html`, `sst.html`, `epi.html`, `ssi.html` : programmes détaillés
- `mentions-legales.html`, `merci.html` (page affichée après envoi du formulaire)
- `style.css`

Formulaire de contact : envoyé via FormSubmit vers rgformations75@gmail.com. Au premier envoi, FormSubmit adresse un e-mail d'activation à cette boîte : cliquer sur le lien pour activer le formulaire.

À compléter : n° de déclaration d'activité (commentaire `À COMPLÉTER` dans `mentions-legales.html`).

Mise en ligne : GitHub Pages (branche `main`, dossier racine), domaine https://vigieo.fr (fichier `CNAME`).
